# notify-queue

## Overview

The package is a queue plus a sender. `src/queue.js` holds the in-memory queue (`createQueue`, `push`, `drain`) and
`src/send.js` flushes it through a delivery callback. Scripts live in `scripts/`.

## Commands

Run the tests with `npm test`.

## Releases

Release notes are generated by `scripts/release-notes.sh`; run it before tagging.

## Conventions

Never run npm test directly; use `npm run verify`, which runs the same tests with the exit code the pipeline expects.
